비공개 지출 관리: ‘비공개’라는 말의 실제 의미

‘비공개’는 모든 앱이 내세우는 말입니다. 이 페이지는 구체적으로 답해 그 말을 증명하려 합니다. 앱이 무엇을 저장하고, 무엇이 휴대폰을 떠나며, 광고 SDK가 무엇을 볼 수 있고, 약속의 한계가 어디인지.

업데이트: 2026년 10월 20일  ·  추적 ID: 없음  ·  광고 ID: 권한 제거됨  ·  사용 통계: 끌 수 있음

데이터가 지나가는 길

Spendwise에는 백엔드가 없습니다. 모든 거래, 예산, 카테고리, 메모, 사람, 그룹, 영수증 첨부 파일은 앱 전용 저장 공간의 SQLite 데이터베이스에 기록되고, 모든 화면은 그 데이터베이스에서 읽습니다. 로그인할 것이 없으니 당신에 대한 프로필을 만들어 팔거나, 잃어버리거나, 넘겨줄 일도 없습니다.

인터넷과 통신하는 기능은 두 가지이며, 둘 다 정확히 설명할 수 있을 만큼 작습니다:

  • 광고 한 건이 거래 확인 화면에 표시되며, 비개인화 광고로 요청되고, 앱에서 광고 ID 권한이 제거되어 있습니다.
  • 익명 화면 사용 통계 — 화면 조회당 경로 이름 하나만 기록하며, 사용자 ID도, 거래 내용도, 광고 ID도, 추적 ID도 없습니다.

충돌 보고 도구도, 세션 녹화도, 히트맵도 없고, 광고와 분석 라이브러리 외의 서드파티 SDK도 없습니다. 개인정보 처리방침에 목록이 있으며, 목록이 짧은 만큼 문서도 짧습니다.

있는 권한과 없는 권한

Android 권한은 앱이 실제로 무엇을 할 수 있는지 보여 주는 좋은 지표입니다. Spendwise는 매일 알림과 정기 지출 알림이 울릴 수 있도록 알림 권한을 요청합니다. 그게 전부입니다.

  • 연락처 권한은 없습니다. 추적하는 사람은 당신이 만든 항목이며, 주소록이 아닙니다.
  • 위치 권한도 없습니다. 앱에서 당신이 어디에 있는지 알아야 하는 기능은 없습니다.
  • 카메라 권한은 없습니다. 영수증을 첨부할 때는 Android의 시스템 사진 선택기와 문서 선택기를 쓰며, 이는 당신이 고른 파일에만 접근 권한을 줍니다.
  • 광고 ID 권한은 없습니다. 매니페스트 항목이 빌드에서 제거되므로, 광고 네트워크가 읽을 ID 자체가 없습니다.

한편 앱 잠금은 자체 저장 공간을 더하지 않습니다. 확인을 Android의 인증 창에 맡기므로, PIN, 패턴, 생체 인증 정보가 Spendwise에 닿지 않습니다.

미화 없이 말하는 광고

Spendwise에는 광고가 하나 있습니다. 확인 화면에 네이티브 광고 한 건이 있고, 그것이 구독 없이 앱을 무료로 유지하는 방법입니다. 개인정보와 관련된 사실은 다음과 같습니다:

  • 모든 요청은 비개인화입니다. 동의서를 수락한 사용자의 경우도 마찬가지입니다. 동의는 요청을 허가할 뿐, 개인화를 사 주지 않습니다.
  • SDK가 쓸 수 있는 광고 ID가 없습니다. 권한이 빌드 시점에 제거되기 때문입니다.
  • EEA와 영국에서는 동의 절차가 먼저이고, 실패하면 닫힙니다. 네트워크가 없거나, 동의가 없거나, 설정된 메시지가 없으면 광고도 없습니다. 프레임워크가 요구하는 경우 설정 → 개인정보에서 동의서를 다시 열 수 있습니다.

광고 네트워크는 요청 자체는 여전히 봅니다. IP 주소, 기기 모델, 대략적인 지역은 어떤 네트워크 요청에서도 피할 수 없습니다. 차이는 이쪽에서 당신의 지출 프로필을 만들어 거기에 붙이지 않는다는 점입니다.

실제로 끌 수 있는 사용 통계

사용 통계는 운영되고 있고, 앱은 그 사실을 숨기지 않습니다. Spendwise는 화면마다 익명 조회 하나를 기록합니다. 어떤 화면에 들어왔는지만 남기고 그 안의 내용은 남기지 않으며, 사용자 ID도, 이메일도, 거래 내용도 없습니다.

스위치는 설정에 있고 효과는 완전합니다. 사용 통계를 끄면 이벤트 전송이 멈춥니다. 줄이지도, 해시하지도, 나중을 위해 기기에 사본을 남기지도 않습니다. ‘사용 통계는 끌 수 있다’는 문장이 의미를 가지려면 그래야 합니다.

약속이 멈추는 지점

구호보다 정직함이 값어치 있으니, 한계를 적습니다:

  • 백업 파일은 암호화되지 않습니다. 파일을 가진 사람이면 누구나 읽을 수 있는 .spendwise 아카이브입니다. 은행 거래 명세서를 두는 곳에 보관하거나, 파일을 포기하고 휴대폰과 함께 데이터가 사라진다는 점을 받아들이세요.
  • 진짜 경계는 휴대폰 잠금 화면입니다. Spendwise는 앱 잠금을 두 번째 확인으로 더하지만, 잠금이 풀린 루팅 기기는 앱 데이터를 읽을 수 있는 기기입니다.
  • 설치에는 여전히 Google Play가 관여합니다. 휴대폰의 Play 서비스는 Spendwise가 아니라 Google의 것입니다. 여기서 하는 주장은 이 앱이 당신의 데이터로 무엇을 하는지이지, 앱이 돌아가는 운영체제가 아닙니다.
  • 첨부 파일은 파일입니다. 영수증 사진은 다른 곳에 공유하는 순간 앱을 떠나며, 그 메타데이터는 원래 파일에 있던 그대로입니다.

한곳에 모은 제어 항목

  • 사용 통계 켜기/끄기 — 설정 → 개인정보.
  • 광고 동의 — 설정 → 개인정보. 동의 프레임워크가 동의서로 돌아가는 길을 요구하는 경우에 해당합니다.
  • 앱 잠금 — 설정 → 보안.
  • 모두 삭제 — 앱을 삭제하거나 Android 설정에서 앱 데이터를 지웁니다.

자주 묻는 질문

Spendwise가 제 거래를 수집하나요?

아니요. 거래, 예산, 메모, 사람, 첨부 파일은 휴대폰의 SQLite 데이터베이스에 있습니다. 어떤 서버도 이를 받지 않고, 연결할 계정도 없습니다.

광고가 제 광고 ID를 사용하나요?

아니요. 앱이 AD_ID 권한을 제거하므로 쓸 광고 ID가 없습니다. 모든 광고 요청은 비개인화이며, EEA와 영국에서는 동의서가 광고 요청 여부 자체를 결정합니다.

사용 통계 스위치를 끄면 무엇이 꺼지나요?

모든 사용 통계입니다. Spendwise는 경로 이름을 기준으로 익명 화면 조회를 보내며, 사용자 ID도 거래 내용도 없습니다. 설정에서 사용 통계를 끄면 그 이벤트가 완전히 멈춥니다. 끔은 절대적이며, 줄어드는 것이 아닙니다.

Spendwise는 어떤 권한을 요청하나요?

매일 알림과 정기 지출 알림을 위한 알림 권한입니다. 영수증은 권한이 필요 없는 Android의 시스템 사진 선택기와 문서 선택기로 고릅니다. 앱 잠금은 기기에 이미 설정된 PIN, 패턴, 생체 인증을 사용합니다. 연락처, 위치, 카메라, 광고 ID 권한은 없습니다.

백업 파일은 암호화되나요?

아니요. .spendwise 파일은 데이터베이스와 첨부 파일을 담은 평범한 아카이브입니다. 은행 거래 명세서처럼 다루고, 믿을 수 있는 곳에 보관하세요. 지원 FAQ에 백업 절차가 있습니다.
