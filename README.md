# Spendwise public site mirror

Read-only mirror of the static site served at <https://spendwise.download>. The source of truth is
the private `expense-tracker` repository; this public copy exists so the project has a verifiable
public code URL.

Do not edit here. Changes are synced from `site/` with `yarn site:mirror` in the private repo.

Every page keeps its canonical URL on `https://spendwise.download`, so this mirror is not a second
indexable copy. No app source, build files, environment variables, or ad unit IDs are published here.
